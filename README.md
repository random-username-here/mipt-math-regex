# `MathRegex` - Учебный движок для конечных автоматов

![Пример](sample.svg)

Учебный движок для конечных автоматов. Содержит в себе:

 - Удобную и шуструю структуру автомата, с поддержкой юникода.
 - Набор функций для комбинации автоматов (операция или, сложение, разные повторы, и прочее)
 - Загрузку автомата из собственного текстового формата и выгрузку в него же / в dot
 - Детерминизацию и минимизацию
 - Построение автомата из регулярки

Далее подробнее о компонентах.

## Текстовый формат для автоматов.

Немного похож на dot.

```py
# это комментарий
# это переход из q0 в q1 по x, затем в q2 по y
q0 - x > q1 - y > q2
# из q1 в q2 с некоторым количеством промежуточных
# финальные состояния с @. Достаточно указать в одном месте.
q0 - a - b - c - d > @q3
# начальное
> q0
```
## Регулярки

Синтаксис вроде стандартных программистских регулярок.

В отличие от промышленных движков вроде pcre (основанных в основном 
на рекурсивном спуске) здесь продвинутые фичи (вроде лукэхеадов, матчащих
групп и подобных) отсутствуют.

 - Любые буквы как буквы
 - `a|b` для одного из
 - `(stuff)` для группировки (не capturing группы)
 - `[abc]` для одной буквы из набора
 - `a*` для повтора от 0 раз, `a+` от 1 раза
 - `a?` для опционального
 - `a{3}` или `a{3,5}` для количества повторов

## Запуск

Требует `cmake` для сборки и библиотеки `xxhash`.

```bash
cmake -B build
cd build
make
./regex [nfa|dfa|mdka] REGEX # выдаст dot представление
./regex nfa '(a+b+)*' | xdot - # удобный просмотрщик
./ops det ../demo/samples/
```

Тесты и codecov запускаются так:

```bash
cmake -B build -DTESTS=1 -DCODECOV=1 -DCMAKE_BUILD_TYPE=Debug
cd build
make tests # просто компилит
make run-tests # ещё и запускает
make run-coverage # ещё и репорт генерит
```

Затем просто берём и открываем `coverage.html`.
